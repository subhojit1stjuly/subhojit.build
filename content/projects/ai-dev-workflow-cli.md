## Overview
A terminal-first productivity utility written in pure Dart that bridges local codebases with LLM developer tools (like Claude Code and GitHub Copilot). It automates boilerplate refactoring tasks, enforces project-specific architecture rules via context injection, and standardizes multi-file code generation templates.
